# Mapeamento DDM -> Modelo Relacional (Stage 1)

## Objetivo

Este artefato consolida a traducao dos 4 DDMs Adabas para um modelo relacional PostgreSQL.
Foco do Stage 1:
- mapear entidades e colunas principais;
- tratar campos MU e grupos PE explicitamente;
- registrar decisoes para reduzir retrabalho no Stage 3 (Flyway/JPA).

## Convencoes de mapeamento

- `A(n)` -> `varchar(n)`
- `N(8)` em formato AAAAMMDD -> `date` (com parse no ETL)
- `N(6)` em formato HHMMSS -> `time`
- `N(14)` AAAAMMDDHHMMSS -> `timestamp`
- `N(p.s)` -> `numeric(p,s)`
- Descriptor (`DE`) -> indice candidate
- Superdescriptor (`Sx`) -> indice composto candidate
- `MU` -> tabela filha (evitar JSONB em dados consultados)
- `PE` -> tabela filha 1:N com coluna de ocorrencia

## Decisoes MU/PE para Stage 1

- MU/PE de dominio transacional e auditoria foram mapeados para tabelas filhas.
- JSONB nao foi escolhido por padrao nesta fase para preservar consultabilidade e integridade relacional.
- Se o time optar por JSONB em algum caso, deve justificar no ADR de persistencia no Stage 2.
